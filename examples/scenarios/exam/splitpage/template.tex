% Scenario: exam / splitpage   (tier: core)
% \splitpage{...}{...} -- the side-by-side two-column layout, and specifically
% its part-lettering contract: items in the LEFT column are (a), (b) and the
% RIGHT column CONTINUES as (c), (d) rather than restarting.
%
% That continuation is the whole point of the construct and the easiest thing to
% regress: it works because global_partno_storage carries the counter across the
% two internal {parts} calls. A regression that reset the counter would produce
% a perfectly good-looking exam with two (a) items on the same question, which
% no build-only check can see -- hence the rendered-label assertions below.
