% Scenario: exam / ppart-points   (tier: core)
% \ppart with DISTRIBUTED point values: \problem[3,4,5]{id} hands each \ppart
% call its own annotation through the Lua part-index state, rather than
% annotating the question as a whole.
%
% That distribution is invisible in a build-only check -- a regression that
% dropped it, or misaligned the values against the parts, still produces a
% perfectly good PDF. The assertions below pin the actual rendered point labels,
% which is the only way to catch it.
