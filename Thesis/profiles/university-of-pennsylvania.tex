% VERIFIED and set here: geometry, spacing.
% LEFT TO THE NEUTRAL FALLBACK: the title page and the approval page. Penn
% prescribes the CONTENT of the title page -- the committee roles below -- but
% the checklist does not give its layout, and the separate Dissertation
% Formatting Guide it refers to was not reachable at a Provost URL on the access
% date. Encoding a plausible arrangement would be exactly the guess this library
% forbids, so the institution-neutral page renders instead.

\thesisinstitution{University of Pennsylvania}

% "In the entire document, left, top, right, and bottom margins are all 1 inch
% of blank space." The checklist is emphatic that the margin stays empty:
% "Page numbers, footnotes, or any part of an illustration or table cannot go in
% the blank margin area" -- which rules out the footer-in-margin arrangement
% several other schools in this set permit.
\thesissetgeometry{left=1in, right=1in, top=1in, bottom=1in}

% "For readability, the document should be double-spaced (2x), except for long
% quotations, footnotes, and the lists of tables, which should be single-spaced."
\thesissetspacing{double}

% --- Accessibility -----------------------------------------------------------
% The Provost's checklist states no accessibility requirement. That is recorded
% as an absence, not filled in from what comparable schools require: a reader of
% this profile should be able to tell "Penn does not publish one here" apart
% from "nobody looked".
\thesisaccessibilityrequirement{Not published}
	{The Office of the Provost's pre-deposit checklist states no accessibility
	 requirement for a filed dissertation. Check the Dissertation Formatting
	 Guide and with grad-degree@provost.upenn.edu before relying on that.}
