# 2026-09-06 — acupuncture-and-massage-college

**blocked** — alphabetical fallback. Round of ten, institution 10 of 10 (the
round completed).

**THE INSTITUTION IS CLOSED.** It ceased operations on 2024-09-02. No student
can file a thesis there, so no profile is possible or useful — this is the
strongest kind of block in the directory so far.

Evidence, opened directly on the access date:

- **ACAHM, "Closed or Previously Accredited/Pre-accredited" list** (the
  accreditation commission's own PDF, served from its site): row *Acupuncture
  and Massage College*, Miami FL — accreditor **ACCSC**, program **MAcCHM**,
  began 5/4/1998, **ended 9/30/2024**, type of status change **"Voluntary
  withdrawal - closure of program"**.
- **`amcollege.edu` no longer serves the college**: HTTPS fails to establish a
  secure connection (curl exit, `http_code=000`); plain HTTP on the bare domain
  returns **404**.

Things a later pass should not have to rediscover:

- **A NEW KIND OF BLOCK REASON — worth generalising.** Every other block in this
  round is about what a live school does or does not publish. This one is about
  the school not existing. The `institutions.csv` worklist is derived from IPEDS
  HD2023, which is a **2023** snapshot, so it necessarily still lists
  institutions that have since closed. Expect more of these as the alphabetical
  queue advances, and check whether an institution is still operating before
  spending a round searching its site for requirements that no longer bind
  anyone.
- **The accreditor's list is the right source for a closure**, and using it does
  not conflict with RESEARCHING.md. That rule governs where a *filing
  requirement* may come from; the fact being recorded here is institutional
  status, not a margin, and the institution's own site is gone.
- **A search-result trap**: querying this college's name together with "DAOM"
  surfaces DAOM catalog text from **atom.edu**, a different and still-operating
  school. None of that describes this institution.
- History, in case the name recurs: founded 1983 as the Acupressure-Acupuncture
  Institute, renamed Southeast Institute of Oriental Medicine (SEIOM) in 2000,
  granted college status and renamed Acupuncture and Massage College in 2003.
  IPEDS UNITID 439969.
