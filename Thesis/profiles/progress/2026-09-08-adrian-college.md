# 2026-09-08 — adrian-college

**blocked** — alphabetical fallback. Round of ten, institution 5 of 10.

Adrian College really does file theses — several master's programs carry
thesis courses and a Thesis Defense — but the college publishes no manuscript
format for them. The Graduate Student Handbook delegates to the programs and
the graduate catalogs say nothing.

Things a later pass should not have to rediscover:

- **The delegation is explicit, so this is a settled "not published", not a
  "not found".** Graduate Student Handbook: "All graduate programs require a
  final project, practicum, and/or thesis. While each program will provide
  details regarding this requirement, it is worthy to note that theses will be
  available in a database searchable by scholars."
- **The 90-page 2024-2025 Graduate Catalog is empty of format.** 69 hits for
  "thesis", every one of them either a course code (ACCT595, MBA560/561,
  ENGL590, SCJ599, SMGT579, HAL602) or the *Thesis Continuation Policy*, which
  is about registration, not layout. Zero hits for margin, title page,
  signature page, double-spac, font. Its eleven "APA" matches are all inside
  "capable" / "capacity" — Adrian does not even delegate to APA in writing.
- **The catalog moved platforms and the newest edition is web-only.**
  `www.adrian.edu/academics/graduate-catalog` now 301s to
  `adrian.smartcatalogiq.com`; the current edition is the *2026-2027 Adrian
  College Undergraduate and Graduate Academic Catalog*, whose top-level contents
  contain no thesis or degree-completion section. The last standalone graduate
  PDF is 2024-2025, at
  `adrian-college.b-cdn.net/files/resources/2024-2025graduatecatalogfinal12.19.24.pdf`.
- **The smartcatalogiq search box does not work through a fetched URL.** Neither
  `?q=` nor `?search=` returns results — the page renders the empty search form
  either way. Navigate the table of contents instead, or use the PDF editions.
- The public site serves assets from `adrian-college.b-cdn.net`; that CDN host
  and `www.adrian.edu` both work.
- The Graduate Student Handbook on the server is the **2022-2023** edition
  (`graduatestudenthandbookfinal2022-2023.pdf`, 28 pp). No newer one was found.
  It is four years old; weigh that if a later pass leans on its wording.
