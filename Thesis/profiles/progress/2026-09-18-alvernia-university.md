# 2026-09-18 — alvernia-university

**blocked** — alphabetical fallback. PR #253. Round of ten, institution 8 of 10.

Alvernia University (Reading, PA) grants a Ph.D. in Leadership with a
dissertation, but its dissertation requirements are not public.

Things a later pass should not have to rediscover:

- **The page that would hold them is behind a login.**
  `alvernia.edu/academics/graduate-programs/phd-leadership/phd-leadership-dissertation`
  — the URL search engines return for "Ph.D. Leadership Dissertation" —
  redirects to `alvernia.edu/user/login`. The public program page
  (`/academics/doctoral/phd-leadership`) describes the dissertation in prose
  only.
- **The catalogs state no format.** The 2023-2024 Graduate Catalog PDF
  (linked from `/coursecatalog`) says only that the dissertation "must report,
  in an accepted scholarly style, an original investigation" (PHD 910–916).
  The current catalogs are Acalog (`catalog.alvernia.edu`, catoid 9 and 10);
  their advanced-search URL returns a zero-byte body to a scripted fetch, as
  other Acalog sites have. Use the Browser pane if a later pass needs to
  search them.
- If Alvernia ever publishes its dissertation guide, deleting
  `blocked/alvernia-university.csv` requeues it.
- No accessibility rule for a filed manuscript was found.
